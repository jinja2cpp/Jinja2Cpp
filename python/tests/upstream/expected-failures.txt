# The pallets/jinja 3.1.6 tests that fail through jinja2cpp, with the reason (docs/tasks/0355).
# python/tests/upstream/run.py runs the suite with fallback="never" and fails on a failure this
# file does not list, on a listed test (its own line, not a prefix) that now passes, and on a
# line that names no test.
#
#   <test id or prefix> <class> [task] <reason>
#
# A prefix (a file, a class, a test without its parameters) covers every test under it. An id
# with spaces is written in double quotes. Classes:
#   internals    Jinja2's lexer, nodes, compiler, debug and utils internals: not counted at all
#   async        async rendering, outside the supported subset (docs/python.md)
#   extension    a custom Extension class, or a builtin extension jinja2cpp lacks
#   unsupported  other API outside the subset: NativeEnvironment, compiled modules, ...
#   deliberate   behaviour Jinja2C++ keeps different on purpose; needs the deciding task
#   divergence   a parity gap; needs the task that owns the fix
# The pass rate is passed / (collected - internals); every other class counts as not passed.

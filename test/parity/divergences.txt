#   kind: output      both render, the output differs
#         rejects     Jinja2C++ reports an error, Python renders
#         accepts     Jinja2C++ renders, Python reports an error
#         unsupported the case needs an Environment option Jinja2C++ does not have
#         unordered   output depends on hash order: may match or differ by platform
#         crash       Jinja2C++ crashes or hits undefined behaviour; the case is skipped, not run
#   task: the docs/tasks/ file that owns the fix (NNNN)
#
# The parity suite fails when a listed case starts to match (delete its line) or changes
# kind (update it), and when an unlisted case diverges. A case blocked by several gaps is
# listed under the first one that has to be fixed; docs/parity.md has the map by area.

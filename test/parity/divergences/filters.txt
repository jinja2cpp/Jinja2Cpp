# Known divergences of Jinja2C++ from Python Jinja2 in the filters area (cases/filters.py).
# Format and kinds: test/parity/README.md.

filters.select_single_pass              output      0101 deliberate: a select/map/reject result can be iterated again; a Python generator is empty the second time
wide.filters.format_c_surrogate         output      0106 deliberate: % formats in UTF-8, where a lone surrogate from %c cannot survive the conversion back to a wide string
filters.lazy_result_truncate            accepts     0401 truncate takes the length of a generator as of a list; Python has no len() for it
filters.lazy_result_unique_hash         rejects     0401 unique hashes a generator as a list; Python hashes it by identity
filters.range_tojson                    accepts     0401 tojson serializes a range as a list; Python's json refuses it

# Known divergences of Jinja2C++ from Python Jinja2 in the methods area (cases/methods.py).
# Format and kinds: test/parity/README.md.

methods.str_encode_bytes               rejects     0403 deliberate: the engine has no bytes type, so str.encode is not a method (docs/python.md)
methods.int_to_bytes                   rejects     0403 deliberate: the engine has no bytes type, so int.to_bytes is not a method (docs/python.md)
methods.float_fromhex                  rejects     0403 deliberate: float.fromhex is an alternate constructor, not a method templates call on a value (docs/python.md)
methods.int_methods_big                rejects@nobigint 0178 build option: without a big-integer backend, arithmetic past int64 raises (-DJINJA2CPP_WITH_BIGINT=boost, docs/parity.md)
